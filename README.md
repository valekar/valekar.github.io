# Rover Wing — valekar.github.io

Portfolio site for Rover Wing, animated educational explainer Shorts for companies.
Single-file `index.html`: Three.js (CDN, importmap) world built entirely in code — a procedural dusk valley, shader sky, clouds, particles, and a code-built drone that lifts off, follows you down the page and lands at the call to action.

Live: https://valekar.github.io/
